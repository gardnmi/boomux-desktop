# Security Policy

Boomux Desktop displays and writes to live terminal sessions. Terminal contents,
clipboard data, environment-derived output, and Agent metadata may be sensitive.

Please report vulnerabilities privately through GitHub's security advisory
workflow for `gardnmi/boomux-desktop`. Do not include terminal transcripts,
credentials, tokens, or private workspace data in a public issue.

Only the latest released version and current `main` branch are expected to
receive security fixes while the project is experimental.
